# Encuesta breve de cierre del piloto

**Instrucciones:** responder es voluntario. Usa una escala de 1 a 5 (1 = totalmente en desacuerdo, 5 = totalmente de acuerdo) y «No aplica / no pude evaluarlo» cuando corresponda. No incluyas información personal ni datos confidenciales.

## Escala

| Ítem | 1–5 / No aplica |
|---|---|
| Supe qué resultado se esperaba en cada actividad. | [ ] |
| Los requisitos previos y la preparación del entorno estaban claros. | [ ] |
| Pude distinguir ejemplos ilustrativos de resultados realmente ejecutados. | [ ] |
| Los criterios de aceptación permitían decidir si una tarea pasaba o fallaba. | [ ] |
| Las instrucciones indicaban qué hacer cuando faltaba evidencia o una dependencia. | [ ] |
| Las medidas de seguridad y las condiciones de parada eran comprensibles. | [ ] |
| Encontré los recursos, ejemplos y plantillas necesarios. | [ ] |
| La carga de trabajo observada fue razonable para el objetivo de la actividad. | [ ] |
| Pude navegar por los materiales con mi método de interacción preferido. | [ ] |
| La evaluación y sus criterios fueron comprensibles. | [ ] |

## Preguntas abiertas

1. ¿En qué paso tuviste que detenerte o pedir ayuda? Describe el paso y el resultado observado, no datos personales.
2. ¿Qué instrucción, término o criterio resultó ambiguo?
3. ¿Qué evidencia te resultó difícil generar o interpretar?
4. ¿Detectaste una barrera de accesibilidad o una alternativa necesaria?
5. ¿Qué cambio único mejoraría más la actividad?
6. ¿Hay alguna observación que no quieras que se incluya en el informe agregado? [explicar el mecanismo aprobado para indicarlo]

## Contexto opcional mínimo

- Actividad sobre la que respondes: [ID]
- Experiencia previa relevante para interpretar la respuesta: [categoría opcional, no texto libre identificable]
- Confianza en tus respuestas: [alta / media / baja]

No pedir nombre, correo, edad exacta, empresa, cuenta de proveedor ni transcripciones de herramientas salvo que exista una necesidad aprobada y documentada.

## Análisis

La persona responsable debe informar número de respuestas por ítem, valores ausentes y tamaño de muestra. No generalizar resultados de un piloto pequeño ni mezclar «No aplica» con una puntuación baja.
