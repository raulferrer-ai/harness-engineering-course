# Product vision

## Purpose

Teach experienced developers to design, build, verify, operate, and maintain software systems that use AI coding assistants and agents, with engineering controls proportionate to risk.

## Audience

Developers with existing software development experience. This is not a beginner programming course.

## Delivery and access

- Open-access educational website.
- Spanish-language learning content.
- Target hosting: Netlify.
- Practical work should have a route that does not require a paid model subscription.
- Prefer provider-neutral concepts and tools; identify vendor-specific examples as examples, not universal requirements.

## Learning principles

- Explain why a practice matters, what can go wrong without it, and how to verify the result.
- Combine conceptual instruction with practical labs and a transversal project.
- Treat security, permissions, testing, evaluation, observability, cost, and recovery as engineering concerns.
- Report uncertainty and limitations; do not promise deterministic model outputs or risk-free automation.
- Design for accessibility and reproducibility from the beginning.

## Scope boundaries

The course does not teach programming from zero, training foundation models from scratch, advanced deep-learning mathematics, or exhaustive tutorials for individual vendors. It does not require a custom learning-management system.
